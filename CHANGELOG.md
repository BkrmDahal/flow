# Changelog

All notable changes to **Flow** will be documented in this file.

---

## [0.6.5] - 2026-05-23

### 🛡️ Privacy-First & On-Device Processing
* **100% Local Inference Philosophy**: Positioned Flow as the premier privacy-first desktop copilot for macOS, running voice dictation (Whisper.cpp) and LLMs (llama.cpp, Ollama, LM Studio) fully on-device without data leakage.
* **Flexible Cloud Integrations**: Maintained full developer freedom by supporting opt-in cloud models (Claude, GPT-4o, Gemini, OpenRouter) and transcription endpoints.

### 🎙️ Instant dictation in any App
* **System-Wide Global Hotkey**: Emphasized native global hotkey triggering to record, transcribe, and refine text instantly in any active macOS application.
* **Streamlined Gatekeeper Resolution**: Replaced long-winded manual de-quarantine instructions in documentation with a clean 1-liner quarantine removal command for developers transferring unsigned local builds between Macs.

### 🤖 Cowork Agent Enhancements
* **Workspace Cleanliness & Scratchpad Separation**: Re-engineered `run_bash` scripts to auto-save to a hidden `.scratch/` subdirectory rather than cluttering the user workspace root.
* **Automatic Deliverable Scanning**: Added a post-task filesystem scanner at turn completion to detect and surface deliverables (like `.xlsx`, `.pdf`, `.csv`, `.py`, `.js`) generated by subprocesses.
* **Enhanced Final File Extensions**: Formally added `.py` and `.js` file types to prompt instructions as first-class, supported deliverable formats.
* **Long-Run Capacity Increase**: Increased the maximum turn iteration limit from **25 to 50 steps** to support larger, more complex agent workflows.
* **Deduplicated File Handling**: Implemented path-based deduplication in the frontend store to ensure deliverables emitted during task execution only display once.
* **Detailed Terminal Diagnostics**: Added automatic tool name logging (`tools=todo_write,run_bash`) directly to the core `── LLM RESP ──` backend console log lines for frictionless debugging.
